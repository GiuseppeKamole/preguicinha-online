# Identidade visual

O arquivo `assets/mascote.jpg` é uma versão reduzida da foto enviada pelo proprietário. Foi utilizado sem acrescentar elementos à cena. Está no README como símbolo visual do projeto, e o repositório continua privado.

Para usar a imagem dentro de uma interface Roblox, envie-a para sua conta por meio das ferramentas oficiais de criação e use o ID do asset autorizado no componente de imagem. A URL do GitHub não é um `rbxassetid` válido.

A imagem contém pessoas; antes de divulgar ou comercializar, confirme os direitos de uso e as autorizações de imagem necessárias.
