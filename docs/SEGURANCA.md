# Segurança

- Não execute carregadores `loadstring` de origem desconhecida.
- Mantenha verificações de dano, recompensas e distâncias no servidor.
- Não inclua tokens, senhas ou chaves de APIs no repositório.
- Faça cópia da experiência antes de executar o instalador, pois ele substitui scripts de mesmo nome.
- Não desabilite o sandbox do Codex para executar scripts desconhecidos.
- Para distribuição pública, confirme que você possui direitos de uso da imagem-símbolo, incluindo consentimento apropriado das pessoas retratadas.
