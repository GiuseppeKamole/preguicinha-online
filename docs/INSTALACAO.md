# Instalação no Roblox Studio

1. Crie ou abra uma experiência de sua propriedade no Roblox Studio.
2. Salve uma cópia antes de executar qualquer instalador.
3. Na Command Bar, cole **todo** o código de `tools/INSTALAR_NO_STUDIO_CommandBar.lua`.
4. Execute uma vez. O instalador cria `SeaForgeServer` em ServerScriptService e `SeaForgeClient` em StarterPlayerScripts.
5. Inicie **Play (F5)** e procure o painel SeaForge Hub.

**Atenção:** o instalador substitui os scripts `SeaForgeServer` e `SeaForgeClient` caso já existam, mas não remove outros scripts. Não cole o instalador em executores de jogos de terceiros.
