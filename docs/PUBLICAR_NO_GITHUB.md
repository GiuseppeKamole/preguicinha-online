# Publicação no GitHub

Este repositório foi atualizado mantendo a branch `backup-original-2026-10-31` com o projeto anterior.

Antes de mudar a visibilidade de **privado** para público, revise dados pessoais, direitos de imagem, licenças e segurança. Para identificar outra marca no GitHub, renomeie o repositório em Settings → General → Repository name (a mudança não foi feita automaticamente).

O GitHub armazena o código. Para executar a experiência, instale os scripts no Roblox Studio; o GitHub não faz scripts de servidor funcionarem em qualquer executor.
