# Compatibilidade

**Suportado como alvo de desenvolvimento:** Roblox Studio, em uma experiência própria, com scripts de servidor e cliente instalados nos serviços corretos.

**Não suportado:** injeção em Blox Fruits, Delta, Synapse e executores similares; `loadstring(game:HttpGet(...))()` não substitui o servidor que implementa o mundo e as regras deste projeto.

O repositório é privado: `raw.githubusercontent.com` não serve como fonte pública acessível de código para executores. A publicação do código não torna suas funções universais.
